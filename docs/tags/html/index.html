Input fields, labels, buttons, and autocomplete elements
Form Category
<label> Active Guide →

Caption for form inputs. Allows text and children with strictly scoped for, class, and id.

<input> Void Tag

Text, number, password, email inputs. Disallows text and children. Supports 10 allowed attributes.

allowsTextContent: false allowsChildren: false
<checkbox> Syntactic Sugar

Convenience mapping to <input type="checkbox"> with checked attribute.

allowsChildren: false checked, disabled
<button> Interactive

Form submission and action triggers. Supports textContent, icons, and native event listeners.

allowsTextContent: true type, disabled
<div> Container

Generic block layout container for input-groups, grid rows, and card wrappers.

allowsChildren: true allowsTextContent: false
<datalist> Autocomplete

Native HTML5 autocomplete dropdown container. Holds <option> children.

allowsChildren: true id, class
<option> Dropdown Item

Datalist or select item definition. Accepts textContent, value, and label.

allowsTextContent: true allowsChildren: false
