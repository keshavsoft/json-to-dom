Developer Quickstart

Get Started in 60 Seconds

Whether you love NPM or prefer a pure HTML file with zero build tools, you're covered.

Option 1: Direct CDN (No Bundler) Fastest 
<div id="app"></div>

<script type="module">
  import jsonToDom from "https://cdn.jsdelivr.net/npm/@keshavsoft/json-to-dom/docs/dist/v42/min.js";

  jsonToDom({
    jsonSpec: {
      tagName: "h1",
      classList: "text-2xl font-bold text-blue-600",
      textContent: "Hello from json-to-dom!"
    },
    targetHtmlId: "app"
  });
</script>
Option 2: Modern NPM / ESM Node & Vite 
# Install via terminal:
npm install @keshavsoft/json-to-dom

# In your JavaScript / TypeScript:
import jsonToDom from "@keshavsoft/json-to-dom";

jsonToDom({
  jsonSpec: {
    tagName: "div",
    textContent: "Compiled dynamically"
  },
  targetHtmlId: "container"
});
