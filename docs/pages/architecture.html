Orchestrator Architecture

Two-Engine Orchestration Pipeline.

@keshavsoft/json-to-dom (v42) is the master orchestrator coordinating two specialized engines: tag synthesis via @keshavsoft/json-to-tag and native container mounting via spec-to-dom.

The v42 Orchestration Pipeline

jsonToDom({ jsonSpec, targetHtmlId, appendPosition, showLog })
  │
  ├─► Engine 1: jsonToTag(jsonSpec)
  │     └─► @keshavsoft/json-to-tag (W3C Node Synthesis)
  │           ├─► json-traversal           ──► Recursive AST walker
  │           ├─► json-to-tag-validate      ──► W3C tag & attribute grammar checking
  │           └─► buildElement             ──► Native DOM node & SVG namespace creation
  │
  └─► Engine 2: specToDom({ buildSpec, targetHtmlId, appendPosition, showLog })
        └─► spec-to-dom (Target Mount Engine)
              ├─► document.getElementById  ──► Target container resolution
              ├─► Collection & Node check  ──► Array, NodeList, HTMLCollection routing
              ├─► Safe Native Mount        ──► append / prepend without innerHTML risk
              └─► Returns container        ──► Live mounted browser HTMLElement

Engine 1: @keshavsoft/json-to-tag

  • Tag Validation: Validates against W3C HTML5 tag dictionaries and allowed attributes.
  • SVG Namespace Support: Transparently creates elements with proper XMLNS namespaces.
  • Zero Mount Side Effects: Pure function returning element trees without mutating the page.
  • NPM Package: @keshavsoft/json-to-tag →

Engine 2: spec-to-dom

  • Target Container Resolution: Safely resolves target container by ID.
  • Collection Flexibility: Mounts single elements, arrays, NodeLists, or collections.
  • Mount Positions: Supports clean replace, append, or prepend.
  • NPM Package: spec-to-dom →

Architectural Evolution

  • v1–v38: Monolithic experimentation combining parser, element creation, and mounting in a single library.
  • v39–v41: Layered chapter separation identifying the boundary between tag synthesis and DOM mounting.
  • v42 (Current): Complete architectural separation — @keshavsoft/json-to-dom orchestrates @keshavsoft/json-to-tag and spec-to-dom as modular, independently testable packages.
