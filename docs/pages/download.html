Integration Tutorial

How to Use min.js

Follow these simple steps to run json-to-dom locally or in production.

1

Place min.js in Your Project

Place min.js next to your HTML file or inside your assets/ or js/ directory:

my-project/
├── index.html
└── min.js   <-- The downloaded engine file
2

Write Runnable HTML Starter Code

Open index.html and include this minimal code snippet: 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My json-to-dom App</title>
</head>
<body>
  <!-- Target Container -->
  <div id="app"></div>

  <!-- Import Local min.js Module -->
  <script type="module">
    import jsonToDom from "./min.js";

    // Call orchestrator
    jsonToDom({
      jsonSpec: {
        tagName: "div",
        classList: "card",
        children: [
          { tagName: "h1", textContent: "Hello World!" },
          { tagName: "p", textContent: "Rendered dynamically with zero dependencies." }
        ]
      },
      targetHtmlId: "app"
    });
  </script>
</body>
</html>
3

Global Window Access: window.ks.jsonToDom

When min.js executes, it automatically attaches to the global browser object at window.ks.jsonToDom: 

// 1. Invoke through the global registry anywhere:
window.ks.jsonToDom.appendToDom({
  jsonSpec: { tagName: "button", textContent: "Click Me" },
  targetHtmlId: "app"
});

// 2. Check engine metadata & version:
console.log(window.ks.jsonToDom.meta);
// Output: { version: "42.1.5", name: "json-to-dom" }
4

Fetch Spec from API or Local JSON

Pipe backend responses or AI outputs directly into the browser DOM without compiling templates: 

import jsonToDom from "./min.js";

async function loadDashboard() {
  const response = await fetch("/api/dashboard-layout");
  const jsonSpec = await response.json();

  // Instantly mounts the complete UI tree
  jsonToDom({ jsonSpec, targetHtmlId: "dashboard" });
}

loadDashboard();
