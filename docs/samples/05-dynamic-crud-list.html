Why Declarative Dynamic Generation?

1. Reusable Factory Functions Wrap item specifications in small factory functions that return a node with one simple call: buildSpecElement({ inSpec: itemSpec }).
2. Direct Node Scoping Because the generated element is a reference in the closure, delete buttons can directly invoke itemNode.remove() without querySelector lookups.
3. Zero Memory Leaks Removing standard DOM elements automatically cleans up attached listeners when the node is detached from the document tree.
