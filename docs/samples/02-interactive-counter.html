How Event Binding Works

1. events Map Any key in events (e.g., click, mouseover, change) is attached using addEventListener(key, fn).
2. Direct Node Reference Handlers receive standard native DOM event objects (e.target, e.currentTarget) with zero wrapper overhead.
3. Live Mutation Because the generated elements are authentic DOM nodes, updating textContent or classes immediately reflects on screen without diffing passes.
