Deep Recursive Tree Construction

1. Arbitrary Depth The engine recursively resolves children arrays to any depth, building grids, containers, badges, and buttons in a single pass.
2. Single Root Insertion All subtrees are linked together in memory and mounted to #dashboard-container with a single appendChild() call.
3. Deterministic Order Children are built in strict preorder traversal, ensuring exact DOM tree fidelity with zero layout shift during assembly.
