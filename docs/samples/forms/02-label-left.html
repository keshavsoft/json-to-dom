Label Left, Input Right (Horizontal)

Horizontal row layout with one input per row. The label sits on the left with a fixed width, and the input expands to fill the remaining row.

CSS Architecture for Label Left

Each row is configured as a flex container: flex items-center. The <label> is given a fixed width w-36 text-xs font-semibold text-slate-700 shrink-0, and the <input> takes the remaining space with flex-1 w-full px-3 py-2 border rounded-lg.
