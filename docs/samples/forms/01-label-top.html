CSS Architecture for Label Above

Each field is enclosed in a block <div>. The <label> uses block text-xs font-semibold text-slate-700 mb-1.5, and the <input> uses w-full px-3 py-2 border rounded-lg. No JavaScript events are attached—pure layout specification.
