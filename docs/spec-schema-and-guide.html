JSON Specification Schema & Authoring Guide

A complete authoring handbook for structuring declarative JSON UI templates for forms, data tables, and dynamic interactive components.

1. Specification Node Schema

Each node in the specification tree is a JavaScript object describing a target DOM element: 

interface ElementSpec {
    tagName: string;                              // Required (e.g. "div", "table", "button")
    textContent?: string;                         // Escaped textual content
    attributes?: Record<string, any>;            // HTML attributes ("id", "class", "placeholder", etc.)
    properties?: Record<string, any>;            // Live DOM properties ("value", "checked", "disabled")
    classList?: string;                          // Space-delimited class string for classList.add()
    events?: Record<string, (e: Event) => void>; // Event listeners ("click", "input", "change")
    children?: Array<ElementSpec | Node>;        // Child specs or native DOM Nodes
}

2. Property Definitions

Field Type Required Description
tagName string Yes Standard HTML tag name passed to document.createElement().
textContent string Optional Plain text to set on element.textContent. Safe from XSS injection.
attributes object Optional Key-value attributes. class sets className; others invoke setAttribute.
properties object Optional Direct DOM properties merged via Object.assign() (e.g. value, checked).
classList string Optional Space-separated CSS class names added using element.classList.add(...).
events object Optional Event listeners registered via addEventListener(eventName, handler).
children Array Optional Nested specs or existing DOM Nodes resolved recursively and appended to parent.

C. Interactive Button with Event Listeners

import { buildSpecElement } from "./src/v2/build/buildSpecElement.js";

const buttonSpec = {
    tagName: "button",
    textContent: "Export Table",
    attributes: {
        type: "button",
        class: "px-4 py-2 bg-blue-600 text-white rounded hover:bg-blue-700 transition"
    },
    events: {
        click: (event) => {
            console.log("Export triggered:", event);
        }
    }
};

const domButton = buildSpecElement({ inSpec: buttonSpec });
document.getElementById("app").appendChild(domButton);

4. Container Rendering Function

To render dynamic specifications to any specific container on your page, you can write a clean mounting function: 

export const renderToContainer = ({ inContainerId = "app", inSpec }) => {
    const localContainerId = inContainerId;
    const localSpec = inSpec;

    const container = document.getElementById(localContainerId) || document.body;
    container.innerHTML = "";

    const domResult = buildSpecElement({ inSpec: localSpec });

    if (Array.isArray(domResult)) {
        container.append(...domResult);
    } else if (domResult) {
        container.appendChild(domResult);
    }
};
