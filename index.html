Two-Engine Pipeline

How json-to-dom Orchestrates Execution

A pure, unidirectional pipeline transforming abstract data into living HTML nodes.

JSON Specification

Pure portable data contract describing tags, attributes, classes, and hierarchy.

@keshavsoft/json-to-tag

npm →

W3C validation and AST traversal producing live DOM node trees.

const buildSpec = jsonToTag(jsonSpec);
3

spec-to-dom

npm →

Resolves target container and mounts DOM elements cleanly.

specToDom({ buildSpec, targetHtmlId });
