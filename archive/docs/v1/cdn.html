CDN Quickstart & Usage

Learn how to include the standalone v42 bundle in your HTML pages with zero npm setup or build tools.

1. Available CDN Endpoints

Choose between the official KeshavSoft GitHub Pages CDN or the jsDelivr npm CDN.

A. KeshavSoft GitHub Pages CDN (Recommended) Fastest 
<script type="module" src="https://keshavsoft.github.io/json-to-dom/dist/v42/min.js"></script>

Alternatively, use the alias /dist/min.js for always-latest bundle.

B. jsDelivr npm CDN npm 
<script type="module" src="https://cdn.jsdelivr.net/npm/@keshavsoft/json-to-dom/docs/dist/v42/min.js"></script>

2. How It Renders in the Browser

You can use either automatic global window registration or direct ES module imports.

Pattern A: Global Window Registration

When the script tag loads, it registers directly to window.ks.jsonToDom.appendToDom. You can invoke it from any module script without needing an import statement: 

<!-- 1. Include the script tag in <head> or <body> -->
<script type="module" src="https://keshavsoft.github.io/json-to-dom/dist/v42/min.js"></script>

<!-- 2. Call anywhere in your script -->
<script type="module">
    window.ks.jsonToDom.appendToDom({
        jsonSpec: {
            tagName: "div",
            classList: "alert alert-primary p-3",
            textContent: "Mounted via window.ks.jsonToDom!"
        },
        targetHtmlId: "dom-render-container",
        appendPosition: "replace"
    });
</script>

Pattern B: Direct ESM Import

If you prefer explicit ES module imports without relying on global scope: 

<script type="module">
    import jsonToDom from "https://keshavsoft.github.io/json-to-dom/dist/v42/min.js";

    jsonToDom({
        jsonSpec: {
            tagName: "h2",
            textContent: "Direct ESM Import Mounting"
        },
        targetHtmlId: "dom-render-container",
        appendPosition: "append"
    });
</script>

3. Full Declarative Pipeline Example

How json-to-dom fits as the final mounting engine in the KeshavSoft declarative instructions pipeline (matching samples/v4/table):

End-to-End HTML Page Complete Specimen 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Declarative Table Pipeline</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4 bg-light">
    <div id="dom-render-container"></div>

    <!-- 1. Pipeline CDNs: Declarative instructions, definitions, and spec -->
    <script type="module" src="https://keshavsoft.github.io/declarative-instructions/dist/v2/min.js"></script>
    <script type="module" src="https://keshavsoft.github.io/declarative-definitions/dist/v2/min.js"></script>
    <script type="module" src="https://keshavsoft.github.io/declarative-spec/dist/v2/min.js"></script>
    <script type="module" src="https://keshavsoft.github.io/json-renderers-run-instructions-steps/dist/v4/min.js"></script>

    <!-- 2. Master DOM Orchestrator CDN -->
    <script type="module" src="https://keshavsoft.github.io/json-to-dom/dist/v42/min.js"></script>

    <!-- 3. Application Execution -->
    <script type="module">
        import columns from "./columns.json" with { type: "json" };
        import data from "./data.json" with { type: "json" };

        const targetHtmlId = "dom-render-container";

        // Fetch instruction step definitions
        const localInstructions = window.ks.declarative.definitions.data.table.simple.instructions;
        const localBaseFromSpec = window.ks.declarative.definitions.data.table.simple.baseFromSpec;

        // Transform data through sequential instruction steps into a declarative JSON spec
        const resultSpec = window.ks.jsonRenderers.runInstructions.steps.runInstructions({
            instructions: localInstructions,
            baseKey: localBaseFromSpec,
            data: { columns, data },
            showLog: false
        });

        // Compile and mount native DOM safely into container
        window.ks.jsonToDom.appendToDom({
            jsonSpec: resultSpec,
            targetHtmlId,
            appendPosition: "replace",
            showLog: false
        });
    </script>
</body>
</html>
