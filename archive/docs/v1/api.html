📖 Developer Reference

API Documentation

Detailed parameters, return values, mount positions, and practical code recipes.

1. Master Function Signature

// Global window call:
window.ks.jsonToDom.appendToDom({ jsonSpec, targetHtmlId, appendPosition, showLog });

// Direct ESM default import:
import jsonToDom from "@keshavsoft/json-to-dom";
const container = jsonToDom({ jsonSpec, targetHtmlId, appendPosition, showLog });

2. Parameters Reference

Parameter Type Default Description
jsonSpec Object | Array required Declarative JSON element specification or an array of specifications.
targetHtmlId String required The HTML ID attribute of the DOM container to mount the elements into.
appendPosition String "append" "replace" empties container before inserting; "append" appends children to end; "prepend" inserts at the start.
showLog Boolean false When enabled, logs tag synthesis and mounting activity to console.

3. Mount Position Behaviors

"replace"

Clean State Replace

Clears the target element's existing contents (container.replaceChildren()) before mounting. Best for data tables, lists, and forms refreshed by user actions.

"append"

Default Append

Appends the synthesized element(s) at the bottom of the container without disturbing existing children.

"prepend"

Top Prepend

Inserts the synthesized node(s) as the very first child of the container. Ideal for live notification banners or feeds.

4. Metadata Inspection

You can query orchestrator version and metadata at runtime: 

console.log(window.ks.jsonToDom.meta);
// Output:
// { version: "42.1.4", name: "json-to-dom" }
